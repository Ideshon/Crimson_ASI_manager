## RU
Что делает:
- Выбирает папку игры или bin64. Если выбрана папка игры и внутри есть bin64, использует bin64.
- Добавляет моды из файлов, папок и архивов.
- Drag-and-drop работает при установленном tkinterdnd2: pip install tkinterdnd2
- Без tkinterdnd2 работает добавление через меню Файл -> Добавить моды.
- ZIP/TAR архивы распаковываются средствами Python.
- 7Z/RAR требуют установленный 7-Zip в PATH.
- Группирует файлы мода: всё из одного архива/папки считается одним модом.
- При сканировании уже установленных .asi ищет рядом файлы с тем же названием, например Mod.asi + Mod.ini + Mod.dll.
- Отключение переносит файлы мода в bin64/ASIModManager/asibak/<mod_id>/ и добавляет .bak к имени файла.
- Включение возвращает файлы обратно.
- Заметки хранятся в bin64/ASIModManager/state.json.
- Можно открыть .ini или выбранный файл через редактор/приложение по умолчанию.
- При замене дубликата старые файлы мода добавляются в bin64/ASIModManager/asiduplicates/previous_files.zip
- Сохранения: открывает найденную папку сохранений Crimson Desert.
- Кэш шейдеров: сначала ищет NVIDIA DXCache, затем AMD/Intel/Windows варианты.
- Управление Ultimate ASI Loader:
  * выбор имени загрузчика через выпадающий список;
  * установка локального DLL/архива/папки;
  * drag-and-drop загрузчика на блок "Ultimate ASI Loader";
  * получение списка версий с GitHub;
  * скачивание x64-ассета выбранной версии;
  * отслеживание текущего загрузчика в bin64;
  * предупреждение, если в bin64 несколько DLL с именами загрузчиков;
  * выбранный загрузчик остаётся в bin64, остальные переносятся в ZIP-архив.
- делать ZIP-бэкап сохранений после закрытия игры, если включена соответствующая галочка.
  * работает, пока менеджер запущен;
  * менеджер отслеживает процесс Crimson Desert через tasklist;
  * когда игра была запущена и потом закрылась, создаётся архив сохранений;
  * архивы лежат в: bin64\ASIModManager\save_backups
  * старые архивы удаляются по указанному лимиту.

**Важно:**
- Перед первым использованием сделайте резервную копию bin64, потому что моды любят ломаться, как будто это их духовная практика.
- После добавления в архив старые .asi/.ini/.dll/прочие файлы удаляются из bin64/asiduplicates и из рабочей папки.
- Если менеджер не был открыт во время закрытия игры, автоматический бэкап после закрытия не сработает. Для ручного бэкапа используй: Инструменты -> Сделать бэкап сохранений сейчас.

Запуск:
1. Установите Python 3.10+ для Windows.
2. Для drag-and-drop:
      py -3 -m pip install tkinterdnd2
3. Запуск:
   1) Обычный запуск:
      - run_crimson_asi_manager.bat
      - Консоль закроется после закрытия окна программы. В этой версии pause убран.
   2) Запуск без консоли:
      - run_crimson_asi_manager_no_console.bat
      - или двойной клик по crimson_asi_manager.pyw.
     
Где хранятся служебные файлы:
- bin64/ASIModManager/state.json
- bin64/ASIModManager/asi_loaders_archive.zip
- bin64/ASIModManager/asibak/
- bin64/ASIModManager/asiduplicates/
- bin64/asimanager_conflict_backups/
- bin64/ASIModManager/save_backups
